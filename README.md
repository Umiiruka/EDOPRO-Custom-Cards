# EDOPRO-Custom-Cards
Open source distribution for personal create-a-card creations. Please enjoy these cards.
Take the .cdb file and move it into the first "expansions" folder of EDOPro.
Take the .lua file and place it with a folder called "script" under the "expansions" folder (if not there, create a new folder with the text: script).

EDOPro FAQ Excerpts:
Q11: How do I play with custom cards or against bots with friends on LAN?
A: You have a couple of options:
1) Port forward the LAN ports used by EDOPro and give your friend your IP to join in LAN mode.
2) You and your friends can set up a VPN like ZeroTier https://www.zerotier.com/ so everybody is on the same virtual LAN. Then you should be able to refresh the LAN room list or connect to the IP provided by the VPN. Both players must have the custom card databases to see what the cards are, and the hosting player must have the card scripts.

You can learn how to script custom cards yourself in ⁠card-scripting-101.
